☕ Coffee Café Website

A simple and responsive café website made using HTML, CSS, and JavaScript.

🌟 Features

Responsive design (works on phone, tablet, and PC)

Multiple pages – Home, Menu, About, Contact

Smooth animations and navigation

Fast loading (PageSpeed 90+)

🛠️ Technologies Used

HTML5

CSS3

JavaScript

📂 Project Structure
Coffee-Caf-Website/
│
├── images/        → all images used
├── index.html     → main homepage
├── about.html     → about page
├── menu.html      → menu page
├── contact.html   → contact page
├── style.css      → main CSS file
└── script.js      → JS file for interactivity

🚀 How to Run

Download or clone the repo

git clone https://github.com/MohammedKaifAli/Coffee-Caf-Website.git


Open index.html in your browser.

💡 Description

This project showcases a stylish coffee café website with clean layout, responsive design, and simple animations.
It’s perfect for learning web design and front-end basics.
